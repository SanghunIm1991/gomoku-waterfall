# Windows向け配布マニュアル

## 1. 文書情報

| 項目 | 内容 |
|---|---|
| プロジェクト名 | 五目並べゲーム (Gomoku) |
| 版数 | 1.0 |
| 作成日 | 2026-08-11 |
| 対象読者 | ①本アプリを配布物（exe）としてビルドする開発者、②ビルド済みexeを受け取って実行する利用者 |

## 2. 目的

本書は、`src/` に実装済みの五目並べゲームを、Python未インストールのWindows PCでも実行できる単体の実行ファイル（`Gomoku.exe`）として配布するための手順をまとめたものである。

- 関連要件: NFR-01（追加パッケージ不要で"実行"できること）、NFR-02（ダブルクリックまたはコマンド実行で起動できること）
- 本書はウォーターフォール開発プロセス（要件定義〜テスト）の成果物に対する、配布工程として追加で作成したものであり、`docs/traceability_matrix.md` の要件対応表（REQ/NFR/CON）とは別建てのドキュメントとして扱う。

## 3. 配布方式の選定

| 方式 | 概要 | 採否 |
|---|---|---|
| ソース配布＋Python実行 | `src/` 一式を配布し、受け取り側で `py src\main.py` を実行 | 不採用（受け取り側にPython環境が必要） |
| **スタンドアロンexe化（PyInstaller）** | `Gomoku.exe` 1ファイルに実行環境を同梱し配布 | **採用**（受け取り側にPythonのインストール不要。NFR-02のダブルクリック起動に合致） |

2026-08-11、ユーザーとの確認によりスタンドアロンexe化を採用することで合意した（`docs/qa_log.md` No.15参照）。

## 4. ビルド環境（開発者向け）

配布用exeのビルドには、CLAUDE.mdに記載の実装環境と同じインタプリタを使用する。

- 使用するインタプリタ: Python 3.9.13（`C:\Program Files (x86)\Microsoft Visual Studio\Shared\Python39_64\python.exe`、`py` ランチャー経由）
- ビルドツール: PyInstaller 6.22.0（本アプリの実行に必要なNFR-01のパッケージ不要要件は"実行時"の話であり、ビルド専用ツールであるPyInstallerはこの要件の対象外と整理する）

### 4.1 PyInstallerのインストール（初回のみ）

```powershell
py -m pip install pyinstaller
```

### 4.2 ビルドコマンド

プロジェクトルート（`D:\claudeProject`）で以下を実行する。

```powershell
py -m PyInstaller --onefile --windowed --name Gomoku --distpath dist --workpath build --specpath build src\main.py
```

オプションの意図:

| オプション | 意図 |
|---|---|
| `--onefile` | 単一の `.exe` にまとめ、配布物を1ファイルで完結させる |
| `--windowed` | コンソールウィンドウを表示させず、GUIアプリとして起動する |
| `--name Gomoku` | 生成物のファイル名を `Gomoku.exe` にする |
| `--distpath dist` / `--workpath build` / `--specpath build` | 生成物・中間ファイルの出力先を `dist/`・`build/` に固定する（いずれもGit管理対象外。`.gitignore` に追加済み） |

### 4.3 ビルド成果物

- `dist\Gomoku.exe` … 配布する実行ファイル本体（このファイルのみを配布すればよい）
- `build\` … PyInstallerの中間生成物（配布不要、Git管理対象外）
- `build\Gomoku.spec` … ビルド設定ファイル（再ビルド時に流用可能。Git管理対象外のため、ビルド手順は本書のコマンドで再現する）

### 4.4 ビルド確認結果（2026-08-11実施）

- 上記コマンドでビルドが正常終了し、`dist\Gomoku.exe`（約9.2MB）が生成されることを確認済み
- `dist\Gomoku.exe` を実行し、プロセスが起動したまま維持される（≒GUIウィンドウが正常に開き、即座にクラッシュしない）ことを確認済み

## 5. 動作環境（配布先PC）

- OS: Windows 10 / 11（64bit）
- Pythonのインストール: 不要（`Gomoku.exe` に実行に必要なPython本体・tkinter一式が同梱されているため）
- 追加ソフトウェアのインストール: 不要

## 6. 配布手順

1. 「4.2 ビルドコマンド」を実行し、`dist\Gomoku.exe` を生成する
2. `dist\Gomoku.exe` のみを配布先に渡す（USBメモリ・共有フォルダ・ZIP圧縮しての送付など、方法は問わない）
3. 配布先PCの任意のフォルダに配置する

## 7. 利用者向け実行手順

1. 受け取った `Gomoku.exe` を任意のフォルダに配置する
2. `Gomoku.exe` をダブルクリックする（NFR-02: ダブルクリックで起動可能）
3. 「五目並べ」ウィンドウが開き、対局を開始できる

## 8. 注意事項

- **SmartScreenの警告について**: `Gomoku.exe` は開発者署名（コード署名）を行っていないため、初回起動時にWindows Defender SmartScreenが「WindowsによってPCが保護されました」等の警告を表示する場合がある。その場合は「詳細情報」→「実行」を選択することで起動できる。本プロジェクトは練習目的のローカル配布であり、署名証明書の取得は対象外とする。
- **ウイルス対策ソフトの誤検知について**: PyInstallerで生成した単一exeは、一部のウイルス対策ソフトで誤検知（False Positive）される場合がある。心当たりのない配布元からのexeではないことを配布時に伝えること。
- 本exeは人対人のみのローカル対局用であり、ネットワーク通信は一切行わない（CON-01）。

## 9. トラブルシューティング

| 事象 | 原因・対処 |
|---|---|
| ダブルクリックしても何も起動しない | 数秒〜十数秒起動に時間がかかる場合がある（単一exe展開の初回オーバーヘッド）。しばらく待っても起動しない場合は、コマンドプロンプトから `Gomoku.exe` を実行しエラーメッセージを確認する |
| SmartScreenで実行がブロックされる | 「8. 注意事項」を参照し、「詳細情報」→「実行」を選択する |
| ウィンドウサイズが画面に収まらない | 本アプリはウィンドウサイズ固定仕様（NFR-05）。ディスプレイの解像度・拡大率を確認する |

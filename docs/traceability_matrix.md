# トレーサビリティマトリックス

要件定義〜テストまでの対応関係を追跡する。1つの表に全工程を詰め込まず、**隣接する工程どうしの対応表（1行=1ペア）**を4つ用意する方式とする。同じIDが複数行に登場してよい（＝一対多・多対一・多対多のいずれも自然に表現できる）。

各工程の成果物を作成・更新するたびに、該当する対応表に行を追記すること（ルールは `CLAUDE.md` の「トレーサビリティマトリックス」章を参照）。
